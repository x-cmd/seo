# Core Content

core_features:
  - Mobile-only Chinese search engine from UC Browser / Alibaba (since 2014)
  - One of the top mobile search engines in China (UC Browser is default on many Android devices)
  - Aggregated index — pulls from Googlebot-crawled pages, Bing, partner APIs, Baidu Tieba/Baike/Zhidao
  - Alibaba ecosystem integration (Taobao, Tmall, 1688, Alipay, Cainiao)
  - UC Browser PUSH JS for URL submission (like Baidu's auto-push)
  - No public webmaster tool — use Google Search Console + Baidu Search Resource Platform
  - Mobile-first technical SEO required
  - AI 智能回答 (AI answers) since 2024

# Key Information

highlights:
  - Mobile-only — desktop ranking doesn't matter
  - Mobile LCP < 3s on 3G required
  - Aggregated index means optimizing for Google + Bing + Baidu covers Shenma
  - Alibaba ecosystem presence (Taobao / Tmall / 1688 / Alipay) helps indirectly
