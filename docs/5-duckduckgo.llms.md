# Core Content

core_features:
  - ~0.7% global search market; higher in privacy-focused segments
  - Mostly backed by Bing's index; 100+ verticals aggregated
  - DuckDuckBot crawler for select verticals (Wikipedia, open data)
  - DuckAssist + AI Chat (privacy-preserving AI features)
  - No `referer` header leaks; no search history stored
  - No personalization / filter bubble
  - Apple Maps for DDG Maps (not Google Maps)
  - No own webmaster tool — use Bing Webmaster Tools
  - Default search in Tor, Brave, Vivaldi Privacy Essentials

# Key Information

highlights:
  - DDG SEO is 95% the same as Bing SEO
  - DDG-specific: Wikipedia presence matters for instant answers
  - DDG-specific: privacy-friendly content gets slight engagement boost
  - DDG-specific: optimize Apple Maps (Apple Business Connect) for local SEO
  - Hard to measure DDG traffic (no referer keyword, no UA snippet)
  - DuckDuckBot UA: Mozilla/5.0 (compatible; DuckDuckBot-Https/1.1; ...)
  - Switched to Bing's index publicly in 2014

# Use Cases

use_cases:

  - Building privacy-respecting sites that DDG users appreciate
  - Local SEO for DDG Maps via Apple Maps / Apple Business Connect
  - Tracking DDG traffic despite no-referer analytics

# Summary

DuckDuckGo SEO in 2026 = Bing SEO (95%) + DuckDuckGo-specific extras (5%). DDG holds ~0.7% global search market; runs DuckDuckBot for select verticals (Wikipedia, open data); mostly uses Bing's index for general web; ships DuckAssist + AI Chat for AI features. Privacy angle: no referer leaks, no search history, no personalization. Hard to track DDG traffic in analytics (no referer keyword). DDG-specific extras: Wikipedia presence matters for instant answers, privacy-friendly content gets slight engagement boost, optimize Apple Maps (Apple Business Connect) for local SEO, allow DuckDuckBot in robots.txt. No own webmaster tool — use Bing Webmaster Tools.
