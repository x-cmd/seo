# Yandex SEO — 俄语搜索、Yandex.Webmaster 与 Yandex.Metrica

**Yandex** 是俄语搜索市场龙头，也是独联体地区最大的科技
公司之一。1997 年成立，总部在莫斯科 / 阿姆斯特丹。Yandex
跑自己的爬虫（YandexBot）、自己的索引（与 Google / Bing
分离）、自己的站长工具（Yandex.Webmaster）、自己的广告平台
（Yandex.Direct）以及自己的网站分析（Yandex.Metrica）。

本文是 Yandex SEO 的 **骨架 / 占位篇**——基础定位、官方
URL 以及 Yandex SEOer 会接触到的入口。详细的排名因子与
分步优化指南会在后续 PR 中补全。

> **TL;DR。** Yandex SEO = 俄语内容 + Yandex.Webmaster
> 验证 + Yandex.Metrica 安装。Yandex 比 Google 更看重行为
> 信号（Metrica 数据）与地理位置。无需 ICP 类备案。

## 为什么是 Yandex？

- **俄语搜索市场约 60%**（2026 年）。
- **俄罗斯、白俄罗斯、哈萨克斯坦等独联体地区的默认搜索引擎**。
- **Yandex 生态**——Yandex.Search、Yandex.Webmaster、
  Yandex.Metrica、Yandex.Direct（广告）、Yandex.Zen / Pulse
  （内容）、Yandex.Maps、Yandex.Taxi。
- **YandexGPT**——Yandex 的大语言模型，集成进搜索作为
  AI 概览答案。

服务俄罗斯 / 独联体用户时，Yandex 是默认搜索引擎；
Google 在该地区份额较小。

## Yandex 的工作原理

- **爬虫**——YandexBot（还有 YandexImages、YandexMedia 等）。
- **索引**——独立于 Google / Bing。
- **NLP**——强俄语形态学，特定语言排名信号。

## Yandex vs Google — 不同点

骨架要点（完整对比后续补充）：

- **行为信号更重**——Yandex.Metrica 数据（跳出率、
  停留时间、浏览深度）回流到排名。安装 Metrica 是 SEO
  相关动作。
- **地理定位权重更高**——Yandex 比 Google 更看重主机 IP
  地理位置与 `.ru` / `.рф` 顶级域名。
- **无需 ICP 类备案**——不同于百度 / 神马，Yandex 不要求
  政府备案才能排名。
- **优先俄语内容**——面向俄语受众，俄语内容排名更高。

## 如何为 Yandex 优化（骨架）

- **俄语内容**面向俄语受众。
- 在 **Yandex.Webmaster**（webmaster.yandex.com）验证站点
  ——提交 sitemap。
- **安装 Yandex.Metrica** 获取行为排名信号。
- **使用 HTTPS**（自 2018 年起必需）。
- **积累 `.ru` / `.рф` 域名的反向链接**。
- **在 robots.txt 允许 YandexBot**。

## Yandex 专属排名因子（骨架）

- **内容质量**——独特的俄语内容。
- **地理 / 主机位置**——主机 IP 影响地理查询。
- **行为信号**——Yandex.Metrica 互动数据。
- **反向链接**——`.ru` / `.рф` 域名加权。
- **HTTPS / 移动端 / 页面速度**——基线。

## Yandex AI 功能（骨架）

- **YandexGPT**——Yandex 的大模型，在部分查询顶部提供
  AI 概览式答案，模式与 Google AI Overviews / Bing
  Copilot 类似。
- 引用高质量俄语来源以出现在 AI 概览引用中。

## 常见 Yandex SEO 错误（骨架）

- **俄语受众却用非俄语内容**。
- **Yandex.Webmaster 未验证**——sitemap 未提交。
- **Yandex.Metrica 未安装**——缺少行为信号。
- **在 `robots.txt` 屏蔽 YandexBot**。

## 快速 Yandex 检查表（骨架）

- [ ] 俄语受众使用俄语内容。
- [ ] 在 Yandex.Webmaster 验证站点。
- [ ] 提交 XML sitemap。
- [ ] 所有页面安装 Yandex.Metrica。
- [ ] 强制 HTTPS。
- [ ] `robots.txt` 允许 YandexBot。
- [ ] 相关域名的 `.ru` / `.рф` 反向链接。

## Yandex vs Google —— 一览（骨架）

| 维度 | Yandex | Google |
| --- | --- | --- |
| 索引 | Yandex 自有 | Google 自有 |
| 爬虫 | YandexBot | Googlebot |
| 站长工具 | Yandex.Webmaster | Google Search Console |
| 网站分析 | Yandex.Metrica（回流排名） | Google Analytics |
| AI 功能 | YandexGPT | AI Overviews |
| 行为信号权重 | 重（经 Metrica） | 较轻 |
| 地理位置权重 | 重 | 中等 |
| 俄语 NLP | 强 | 较弱 |
