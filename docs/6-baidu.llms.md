  - ICP filing required for mainland-China sites (otherwise suppressed)
  - Baidu Search Resource Platform (ziyuan.baidu.com) — free webmaster tool
  - 4 ways to submit URLs: sitemap, manual, API, auto-push JS
  - Auto-push JS snippet (//push.zhanzhang.baidu.com/push.js)
  - Baidu weighs title, meta keywords, keyword density more than Google
  - Baidu favors older Chinese domains; weights `.cn` / `.com.cn` backlinks more
  - Baidu Tieba / Baike / Zhidao ecosystem integration
  - Baidu AI 摘要 + Wenxin Yiyan (Ernie) for AI features

# Key Information

highlights:
  - ICP filing takes 7-20 days via host provider (Aliyun, Tencent Cloud)
  - 公安备案 additionally required for UGC sites
  - Indexing is slow: 1-4 weeks for new sites (Google: 1-7 days)
  - HTTPS required since 2015
  - Meta keywords tag is read (Google ignores it)
  - Keyword density 2-3% historically important
  - Baidu-specific schemas: Baidu 通用 (Tongyong)
  - MIP (mobile instant page) framework mostly deprecated in 2026

# Summary

Baidu SEO in 2026 = ICP filing + Simplified Chinese content + Baidu Search Resource Platform + Tieba/Baike/Zhidao presence. Baidu holds ~75% Chinese-language search market; Google is blocked in mainland China, so Baidu is the default. ICP filing is required for mainland-hosted sites (and required for Apple App Store in China). Baidu weighs title, meta keywords, keyword density, and domain age more than Google; meta keywords tag is read (Google ignores it). Four URL submission methods: sitemap, manual, API (1000 URLs/submit, 10 submits/day), and auto-push JS snippet. Baidu runs its own AI features (AI 摘要 + Ernie); same pattern as Google/DuckDuckGo AI — cite high-quality sources, long-form first-hand Chinese content wins. Indexing is slow (1-4 weeks for new sites vs Google's 1-7 days).
