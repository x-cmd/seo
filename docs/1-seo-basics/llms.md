# Core Content

core_features:
  - SEO = Crawl → Index → Rank pipeline
  - Submit XML sitemap to Google Search Console, Bing Webmaster Tools, Baidu Search Resource Platform
  - Use robots.txt to control bot access; declare sitemap location
  - Add JSON-LD structured data (Article, Product, FAQPage, HowTo, Organization)
  - Build backlinks — submit to directories, guest posts, original research
  - Match Core Web Vitals (LCP < 2.5s, INP < 200ms, CLS < 0.1)
  - 30-minute first-time indexing checklist

# Key Information

highlights:
  - Google holds ~91% of global search market; Bing ~3.5%; Baidu ~1.5%; Yahoo < 1%
  - Small sites can be indexed in days (Google) to weeks (Baidu)
  - IndexNow gives same-day indexing on Bing / Yandex / Seznam
  - JavaScript-only rendering is the #1 small-site SEO mistake
  - Backlinks are the #1 off-page ranking factor
  - Mobile-first indexing since 2018; HTTPS required since 2014

# Summary

SEO = Crawl → Index → Rank. To get a small site indexed fast: submit an XML sitemap to Google Search Console, Bing Webmaster Tools, and Baidu Search Resource Platform; write a sensible robots.txt; add JSON-LD structured data; build a handful of quality backlinks; and wait. The four practical levers are technical health (Core Web Vitals), content quality + E-E-A-T, structured data, and off-page authority. Common small-site mistakes: no internal linking, JavaScript-only rendering, slow pages, duplicate content, thin content, buying links. Tools: free webmaster tools from each engine, Lighthouse, schema validators, Screaming Frog for crawling.
