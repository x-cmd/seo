# Core Content

core_features:
  - Yahoo web search uses Bing's index since 2009 (extended 2015)
  - Yahoo! Slurp crawler still runs independently of Bingbot
  - Yahoo News, Finance, Sports, Mail — Yahoo's own product ecosystem
  - Yahoo Answers shut down in 2021 (read-only archive remains)
  - IndexNow submissions picked up by Yahoo automatically (via Bing)
  - Yahoo weighs domain age, .com/.net TLD, and exact-match keywords slightly more than Bing
  - No current Yahoo-only webmaster tool — use Bing Webmaster Tools

# Key Information

highlights:
  - ~1.5% global search market; ~2.5% US desktop
  - Yahoo! Slurp user agent: Mozilla/5.0 (compatible; Yahoo! Slurp; ...)
  - Allow Yahoo! Slurp in robots.txt — don't block
  - Yahoo News Publisher: https://partner.yahoo.com/
  - Yahoo Finance is one of the largest PR distribution networks
  - For Yahoo web (Bing-powered): optimize for Bing once
  - For Yahoo News / Finance: separate publisher surfaces

# Use Cases

  - Submitting to Yahoo News for editorial visibility
  - Allowing Yahoo! Slurp crawler in robots.txt
  - Distributing press releases via Yahoo Finance
  - Tracking Yahoo search traffic in analytics

# Summary

Yahoo Search in 2026 = Bing's index (since 2009) + Yahoo's own crawlers (Yahoo! Slurp) + Yahoo's own product ecosystem (Yahoo News, Finance, Mail). Yahoo web results optimization is 90% the same as Bing optimization — content quality, backlinks, E-E-A-T-like signals, HTTPS, mobile, page speed, structured data. The Yahoo-specific 10%: domain age, .com/.net TLDs, exact-match title/URL keywords, and being cited in Yahoo News / Yahoo Finance. Allow Yahoo! Slurp in robots.txt; submit to Yahoo News Publisher for editorial visibility. IndexNow submissions are picked up by Yahoo automatically (via Bing). No current Yahoo-only webmaster tool — use Bing Webmaster Tools.
