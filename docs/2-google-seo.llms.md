# Core Content

core_features:
  - Google holds ~91% of global search market (StatCounter Q2 2026)
  - E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness)
  - Core Web Vitals: LCP < 2.5s, INP < 200ms, CLS < 0.1
  - Helpful Content Update — target first-hand experience
  - AI Overviews (formerly SGE) — long-form first-hand content wins citations
  - Structured data (JSON-LD, Schema.org) for rich results
  - Google Search Console — Performance / Coverage / URL Inspection / Sitemaps / Enhancements
  - Manual + algorithmic penalties (cloaking, link spam, thin content)

# Key Information

highlights:
  - Mobile-first indexing since 2018; HTTPS required since 2014
  - Position 1 CTR ~30%; position 4-10 CTR ~5%; below position 11 < 2%
  - Backlinks remain the #1 off-page factor
  - AI Overviews shift clicks down; being cited still drives awareness
  - Free tools: Search Console, PageSpeed Insights, Lighthouse, Rich Results Test
  - For YMYL topics, E-E-A-T is enforced more strictly

# Summary

Google SEO in 2026 = E-E-A-T + Core Web Vitals + Helpful Content + structured data + AI Overview optimization. Google Search Console is the free day-to-day tool: Performance (impressions/clicks/CTR/position), Coverage (excluded pages), URL Inspection (single-URL health), Sitemaps, Enhancements (rich results). Ranking factors are bucketed into content quality (E-E-A-T, Helpful Content), technical (Core Web Vitals, mobile-first, HTTPS, structured data), off-page (backlinks), and user signals (CTR, dwell time). AI Overviews (since 2025-05, formerly SGE) shift clicks down; long-form first-hand content wins citations. Penalties: manual actions are visible in GSC and recoverable; algorithmic drops (e.g. Helpful Content demotion) require auditing content for first-hand experience + value.
